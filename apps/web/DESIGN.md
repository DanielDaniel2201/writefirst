# Write First Web Design

The marketing site is one responsive screen. Its job is to express the product idea and let the visitor download the current Chrome extension without introducing a second content page.

## Page structure

1. Centered Write First brand, with a language switch at the top right.
2. One large bilingual slogan. The final phrase is styled as an input field.
3. A passive translation card directly below that field to demonstrate the product in the slogan itself.
4. One download action and the three compact unpacked-extension installation steps.

English is the default locale. The Chinese version uses the exact slogan `先表达真正想说的话，再看目标语言怎么说`.

## Visual direction

- warm off-white canvas
- black editorial-scale headline
- deep green brand mark and primary action
- thin neutral borders and a restrained card shadow
- no additional sections, navigation, feature grids, FAQ, or decorative imagery
- the product demonstration is the hero composition, not a separate screenshot

## Product boundaries

The card must remain visibly passive. Copy must not imply that Write First rewrites, inserts, or submits the user's text. Do not add speculative features, testimonials, analytics claims, or account features.

## Responsive behavior

Preserve the same hierarchy on desktop and mobile. On narrow screens, allow the input phrase to wrap inside its border and let the installation hint wrap below the full-width download button.
