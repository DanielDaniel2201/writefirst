安装

开始使用

下载 ZIP 压缩包，解压后加载到 Chrome，再完成基础配置。

01

下载 ZIP 压缩包

这是当前唯一的扩展下载方式。

下载 ZIP 压缩包 ↓
02

解压并加载

解压文件，在 Chrome 扩展程序页面开启开发者模式，点击“加载已解压的扩展程序”，选择解压后的文件夹。

03

完成基础配置

填写目标语言、Base URL、Model 与 API Key，保存后刷新要使用的网页。

第一次设置完成后，即可在常见网页输入框里测试。
