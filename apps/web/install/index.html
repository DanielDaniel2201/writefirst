安装与配置

三步装好扩展，再用你自己的接口开始翻译。

Write First 当前以 Chrome Manifest V3 扩展形式提供。下载压缩包、在 Chrome 中加载、填入语言和接口设置后，就可以在真实网页输入框里开始测试。

下载扩展包 返回首页
Popup 设置界面
01

下载并解压扩展包

点击“下载扩展包”后，解压 write-first-extension.zip，保留包含 manifest.json 的目录。

02

在 Chrome 中加载 unpacked extension

  1. 打开 chrome://extensions
  2. 打开右上角的 Developer mode
  3. 点击 Load unpacked，选择刚才解压后的扩展目录
03

完成基础配置并开始测试

打开扩展 Popup，设置源语言、目标语言、Base URL、Model 与 API Key。随后在任意常规文本输入框里输入至少两个可见字符并停顿，即可看到旁注卡片。

建议先检查这些设置

  • Base URL 如果未以 /chat/completions 结尾，扩展会自动补全。
  • 返回内容应只有自然的目标语言翻译，不需要解释、注释或引号。
  • 扩展启用后，只有用户当前输入的文本会发送到配置的接口。

配置边界

产品行为尽量克制，尽可能不打断用户当前写作流程。

会工作的输入区域

普通文本输入框、搜索框、textarea，以及常见 contenteditable 编辑区域。

会被跳过的字段

密码、邮箱、电话、URL、数字、OTP、支付类、hidden、disabled、readonly 等敏感或不适用字段。

卡片何时出现

用户停止输入 800ms，且当前文本有至少 2 个可见非空白字符时，请求翻译并显示卡片。

卡片何时消失

继续输入、清空文本、失焦、元素移除、扩展关闭或出现更新请求时，旧卡片会立即隐藏。
