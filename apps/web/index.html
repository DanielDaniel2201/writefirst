Write First / Chrome Extension

先表达你真正想说的话，再看目标语言怎么说。

Write First 不替你写，不替你发，也不替你改。它只在你停下来的一刻， 把同一句话在目标语言里的自然表达安静地放在输入框旁边。

产品理念

不是代写工具，而是把“我刚想说的话”翻成目标语言给你看。

学习材料来自用户当下真的想表达的内容

用户不是先读一批被设计好的练习句子，而是在真实搜索、评论、记录、沟通的瞬间， 看到自己这句话在另一门语言里会怎么自然地说。

翻译卡片只负责呈现，不负责操作

卡片不会插入文字，不会变成新的编辑器，也不会引导用户“接受建议”。 它是一条安静的旁注，帮助比较、记忆和内化。

使用场景

在最容易产生表达欲的地方学习，而不是跳到另一个学习界面。

搜索框

准备搜索一个问题时，先用母语写出来，再顺手对照目标语言怎么组织关键词与语气。

评论区与社交输入框

想回复、想发言、想表达观点时，旁边立即出现更自然的目标语言说法，帮助用户慢慢从“看懂”转向“会说”。

个人笔记与草稿

记录想法、列待办、写提纲时，用户面对的是自己最熟悉、最有记忆点的内容，因此更容易形成长期语言积累。
